# Windows-версія (Electron)

Гра для Windows — це ті самі файли, що й на сайті, у вікні програми на Electron (вбудований Chrome, той самий рушій, що
в Android). Збирає її GitHub після кожного оновлення, разом з Android-версією і з тим самим номером версії.

## Як встановити

1. Відкрийте реліз [Windows (latest)](https://github.com/vivites753-coder/lemonade-king-njx5t211/releases/tag/windows-latest)
   і завантажте `lemonade-king-setup.exe`.
2. Запустіть. Інсталятор не підписаний сертифікатом, тож Windows покаже синє вікно SmartScreen: натисніть «Докладніше»,
   потім «Запустити все одно». Адміністратор не потрібен.
3. Гра встановиться в `%LOCALAPPDATA%\Programs\lemonade-king`, ярлики з'являться на робочому столі й у меню «Пуск».

## Оновлення

Встановлена гра сама дивиться в цей реліз (файл `latest.yml`) під час запуску й кожні 4 години. Нову версію вона тихо
завантажує й показує смужку «Вийшла нова версія гри! Оновити»: натискання зберігає гру, ставить нову версію й запускає
її знову. Якщо не натискати, нова версія встановиться, коли гру закрити.

Копія для Steam (архів `lemonade-king-steam-win64.zip`, у ній є файл `resources/steam`) сама не оновлюється: її оновлює
Steam, див. [STEAM.md](STEAM.md).

## Як грати на комп'ютері

- Мишка: клік — як дотик; колесо — наближення; права або середня кнопка, затиснута, — рух поля.
- `F11` або `Alt+Enter` — повний екран або вікно (гра запам'ятовує вибір).
- «Налаштування» → «Вийти з гри».
- Збереження лежать у `%APPDATA%\Lemonade King`; прогрес окремий від сайту й телефона, перенести можна експортом та
  імпортом у налаштуваннях.

## Для розробки

| Команда | Що робить |
|---|---|
| `npm run desktop` | збирає гру й відкриває її в Electron |
| `npm run desktop:smoke` | те саме без вікна: перевіряє, що гра, картинки й звук вантажаться, і закривається |
| `npm run desktop:build` | інсталятор і папку `release-win/win-unpacked` (як на GitHub) |
| `electron desktop --shots=<папка> --lang=uk` | знімки екрана 1920×1080 для Steam (`desktop/shots.cjs`) |
| `"Lemonade King.exe" --check-update` | без вікна: що встановлена копія знаходить на GitHub і чи може завантажити |

Файли: `desktop/main.cjs` (вікно, адреса `app://game/`, оновлення), `desktop/preload.cjs` (кілька викликів для гри,
`src/desktop.ts`), `desktop/build/icon.ico`, `electron-builder.yml`, `scripts/desktop-prepare.mjs` (копіює `dist` у
`desktop/game`), задача `windows` у `.github/workflows/android.yml`.

Застереження: у папці, яку застосунок Claude зробив для сесії, особливі права доступу, і пісочниця Chromium
відмовляється звідти запускатися. Для перевірок там Electron запускався з копії в `%TEMP%`; у звичайній папці (і в
установленій грі) такого немає.
