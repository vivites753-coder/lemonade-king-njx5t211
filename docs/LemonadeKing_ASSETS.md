# 🎨 Lemonade King — список графіки для генерації

Усе, що треба намалювати/згенерувати. Спочатку гра працює на **заглушках, намальованих кодом**; кожен ресурс у цьому списку має **ID**, під яким код його шукатиме. Поклали PNG з потрібною назвою в потрібну папку — він автоматично замінює заглушку.

---

## 1. Єдиний стиль (дати в кожен запит до генератора)

**Базовий промпт-стиль** (скопіюйте перед описом кожного об'єкта):

> Isometric 3D render of **[ОБ'ЄКТ]**, cute stylized soft clay / toy-like look, rounded chunky shapes, bright cheerful saturated colors (lemon yellow, fresh green, sky blue, warm orange), soft studio lighting from the top-left, gentle ambient occlusion, **true isometric 2:1 dimetric camera (about 30° elevation, rotated 45°)**, clean readable silhouette, kid-friendly game asset, **isolated on a fully transparent background**, no ground shadow, no text, no watermark, centered.

**Негативний промпт:** realistic, photo, dark, scary, noisy, text, watermark, background, ground shadow, perspective distortion, fisheye.

### Жорсткі правила узгодженості
1. **Одна й та сама камера** для всіх об'єктів: ізометрія 2:1 (ребра тайла йдуть під кутом ≈26,57° — «піксельна» ізометрія 2:1, **не** 30°/30° «справжня»). Якщо генератор ламає кут — використовуйте референс-тайл (п. 3) як початкове зображення.
2. **Світло завжди зверху-ліворуч**, тіні мʼякі, **без запечених тіней на землі** (тінь малює гра).
3. **Прозорий фон**, PNG, без обрізання країв, поля ≥ 8 px.
4. Палітра обмежена: жовтий `#FFD93B`, лимонно-зелений `#8FD16A`, бірюзовий `#2BB3A3`, небесний `#7CC8F0`, помаранчевий `#FF9F43`, рожевий `#FF7AA8`, коричневий `#8A5A35`, кремовий `#FFF8E1`.
5. Обличчя людей — прості (точки-очі, маленький рот), пропорції «чібі»: велика голова.
6. Жодного тексту на об'єктах (надписи на банері, вивісці та дошці гра малює сама, щоб їх можна було перекладати) — залишіть **чисту площину**.

### Розміри (початкове зображення)
| Група | Розмір PNG | Примітка |
|---|---|---|
| Тайл землі | **128×64** (ромб) + 16 px товщини для крайових | Один ромб, 4 варіації |
| Малі об'єкти (предмети) | 128×128 | |
| Середні (дерево, лавка, столик) | 256×256 | |
| Великі (будинок, школа) | 512×512 | |
| Персонажі | 128×192 | Висота ≈ 1,5 тайла |
| Іконки UI | 128×128, пізніше зменшуємо до 64 | Плоскі, з обводкою, **не** ізометричні |

> У грі всі спрайти показуються вдвічі меншими (для чіткості на дисплеях Retina/Android).

## 2. Структура папок і іменування

```
assets/
  tiles/        tile_*.png
  buildings/    bld_*.png
  props/        prop_*.png
  stand/        stand_*.png
  items/        item_*.png
  chars/        char_*.png
  fx/           fx_*.png
  ui/           ui_*.png
  bg/           bg_*.png
```
Іменування: `група_назва_варіант.png`, малі літери, англійською, без пробілів. Приклад: `char_kid_a_front.png`, `char_kid_a_back.png`.

Пріоритет: **P0** — потрібно для першого прототипу (етап 1 з усіма механіками), **P1** — етап 2–3, **P2** — етап 4–6, **P3** — прикраси.

## 9. Персонажі

### Правило економії
Для кожного персонажа потрібні **лише 2 зображення**: **«обличчям до камери»** (`_front`, дивиться вниз-вправо) та **«спиною до камери»** (`_back`, дивиться вгору-вліво). Ліві напрямки гра отримує дзеркальним відображенням. Ходьба — програмна (покачування/підстрибування), кадри не потрібні. Пізніше за бажанням додаємо 2 кадри ходьби.

Усі в **нейтральній позі стоячи**, руки опущені, пропорції «чібі».
