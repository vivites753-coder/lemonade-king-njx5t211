# Lemonade King для Android

Гра загорнута в Android-додаток через [Capacitor](https://capacitorjs.com): усередині додатка та сама гра (`dist`), що й на сайті, лише в повноекранному WebView. Інтернет для гри не потрібен.

## Як отримати додаток

Після кожного оновлення гри в `main` GitHub сам збирає додаток (workflow **Android app**, `.github/workflows/android.yml`) і кладе файли в реліз **Android (latest)**:

- `lemonade-king.apk` — щоб встановити на телефон напряму;
- `lemonade-king.aab` — для завантаження в Google Play.

Щоб встановити на телефон: відкрити реліз на телефоні, завантажити `lemonade-king.apk`, відкрити його й дозволити встановлення «з невідомих джерел» для браузера. Нова версія встановлюється поверх старої, і збереження лишаються.

Збереження на сайті й у додатку окремі. Щоб перенести гру, у налаштуваннях на сайті натисніть «Зберегти у файл», а в додатку — «Завантажити з файлу».

## Що зроблено в додатку

- Лише горизонтальний екран, без рядка стану й кнопок навігації (свайп від краю показує їх на мить) — `MainActivity.java`, `AndroidManifest.xml`.
- Розмір шрифту з налаштувань телефона не ламає розкладку гри (`setTextZoom(100)`).
- Виріз камери й краї екрана: Capacitor SystemBars (safe-area insets).
- Кнопка «Назад» закриває вікно або підказку; якщо нічого не відкрито — питає, чи вийти (`src/native.ts`).
- Коли додаток згортають, продаж стає на паузу.
- «Зберегти у файл» відкриває меню «Поділитися» телефона (Файли, Диск, месенджер).
- Немає перевірки оновлень із сайту й кнопки «Повний екран» — додаток оновлюється новою версією APK.
- Значок і заставка зроблені зі значка гри: `python tools/make_android_icons.py` (запустити знову, коли значок зміниться).

## Ключ підпису

Додаток підписано ключем `lemonade-upload.p12` (папка `.keys/`, її немає в git). GitHub бере ключ із секретів репозиторію `LK_KEYSTORE_BASE64`, `LK_KEYSTORE_PASSWORD`, `LK_KEY_ALIAS`.

**Збережіть копію папки `.keys/` у надійному місці.** Кожне оновлення має бути підписане тим самим ключем, інакше телефон не встановить нову версію поверх старої. У Google Play з «Play App Signing» це ключ завантаження: якщо його загубити, його можна замінити через підтримку Play Console.

## Ідентифікатор додатка

`io.github.vivites753coder.lemonadeking` (`capacitor.config.ts`, `android/app/build.gradle`). Після першого завантаження в Google Play його вже не можна змінити.

## Google Play: що потрібно від власника

1. Акаунт розробника Google Play (одноразовий внесок, перевірка особи).
2. Для нового особистого акаунта Google вимагає закрите тестування: щонайменше 12 тестувальників протягом 14 днів, перш ніж відкриється публікація для всіх.
3. Сторінка в магазині: назва, короткий і повний опис, значок 512×512, банер 1024×500, знімки екрана з телефона.
4. Політика конфіденційності (посилання на сторінку) — обов'язкова, особливо для дитячих ігор. Гра нічого не збирає й не надсилає: усе зберігається на телефоні.
5. Анкети в Play Console: вікова категорія (контент), цільова аудиторія (діти → правила програми «Families»), безпека даних (дані не збираються), реклама (немає).
6. Завантажити `lemonade-king.aab` з релізу **Android (latest)**.

## Зібрати вручну (за потреби)

Потрібні Node.js, JDK 21 і Android SDK (або Android Studio):

```
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleRelease
```

Для підписаної збірки на своєму комп'ютері створіть `android/keystore.properties` (він не потрапляє в git):

```
storeFile=../../.keys/lemonade-upload.p12
storePassword=<пароль із .keys/password.txt>
keyAlias=lemonade
```
