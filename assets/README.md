# Графіка гри (PNG)

Кладіть сюди PNG-файли з **точною назвою ID** зі списку `LemonadeKing_ASSETS.md`:

```
assets/tiles/tile_grass_1.png      ← варіанти тайлів: _1 … _4 (або один tile_grass.png)
assets/props/prop_tree_a.png
assets/buildings/bld_house_yard.png
assets/stand/stand_table.png
assets/chars/char_kid_a_front.png  ← і char_kid_a_back.png
...
```

* Гра знаходить файли сама (і в `npm run dev`, і в збірці). Якщо файла немає — малюється заглушка з коду.
* Щоб нові картинки потрапили у `Lemonade King.html`, запустіть **`Оновити гру.bat`** — картинки вбудуються прямо у файл.
* Назва підпапки неважлива, важлива **назва файла**.
* Розмір і точку прив'язки (де «ноги» об'єкта) налаштовуйте в `src/render/spriteMeta.ts`:
  `h` — висота на екрані у світових пікселях (тайл = 64×32), `anchor` — точка картинки, яка ставиться на місце об'єкта (`[0.5, 1]` = низ по центру).
* Персонажі: `_front` (обличчям до камери) і `_back` (спиною). Ліві напрямки гра робить дзеркалом.
